# Vic API 精选 · 第 009 期 · 2026-11-15（周日）
主题：给 Agent 装上「黑匣子 + 办公室 + 仓库」——观测、协作、存储、物流追踪与收款的 10 个免费 API
额度均于 2026-11-15 核对官方页面。

1. Langfuse — 黑匣子｜Agent 全链路观测
- 网址 https://langfuse.com ；文档 https://langfuse.com/docs
- 注册：邮箱/Google/GitHub 登录，Hobby 计划免费，无需绑卡
- 额度：Hobby 免费：每月 5 万 units、保留 30 天数据、2 个用户、摄取 1,000 请求/分钟、通用 API 30 请求/分钟；开源可自托管免费
- 用法：Python/JS SDK、OpenTelemetry，或经 Langfuse AI Gateway/LiteLLM 代理记录
- Agent 适配：官方 MCP 与 CLI；Trace、会话、Token 与成本追踪、提示词版本管理、评测
- 场景：盯住你的外贸客服 Agent 每次调用花了多少钱、哪一步出错
- 匹配度 ★★★★★

2. Sentry — 报警器｜报错监控与 MCP
- 网址 https://sentry.io ；MCP https://mcp.sentry.dev
- 注册：邮箱/Google/GitHub 登录，选 Developer 免费计划
- 额度：Developer 免费：仅 1 个用户、5k 错误、5M spans、5GB 日志、50 次会话回放、10 个自定义仪表盘、30 天回溯，含 MCP 访问
- 用法：各语言 SDK 一行初始化；Sentry CLI；MCP 让 Agent 直接读报错
- Agent 适配：Agent Tracing、MCP 监控、官方 MCP 服务器
- 场景：你的自动化脚本、网站下单流程出错时第一时间知道
- 匹配度 ★★★★☆

3. PostHog — 数据罗盘｜产品分析与 AI 观测
- 网址 https://posthog.com ；文档 https://posthog.com/docs
- 注册：邮箱/Google/GitHub 登录，页面写明无需绑卡
- 额度：每月免费且按月重置：分析 100 万 events、错误追踪 10 万 exceptions、AI Observability 10 万 events、问卷 1500 份回复
- 用法：JS/Python 等 SDK 或 HTTP 采集接口
- Agent 适配：官方 MCP；可追踪 LLM 调用与评测
- 场景：自媒体落地页转化、外贸独立站访客行为分析
- 匹配度 ★★★★☆

4. Gmail API — 收发信手｜邮箱自动化
- 网址 https://developers.google.com/workspace/gmail
- 注册：Google Cloud 控制台新建项目 → 启用 Gmail API → 配 OAuth 同意屏幕
- 额度：官方称标准使用无额外费用；每项目 120 万 quota units/分钟，每用户 6,000/分钟；每日计费阈值 8,000 万 units；单封邮件最多 500 收件人
- 用法：REST 或各语言客户端库；messages.send 为 100 units
- Agent 适配：官方 Gmail MCP 服务器（搜索邮件线程、建草稿、打标签）
- 场景：外贸询盘自动分类、起草回复草稿、跟进未回复客户
- 匹配度 ★★★★★

5. Google Calendar API — 日程官｜排期与会议
- 网址 https://developers.google.com/workspace/calendar
- 注册：同一 Google Cloud 项目启用 Calendar API，OAuth 授权
- 额度：官方称标准使用无额外费用；每项目 10,000 请求/分钟，每用户 600/分钟；每日计费阈值 100 万请求
- 用法：REST；events.insert/list，freebusy.query 查空闲，支持推送通知
- Agent 适配：官方 Calendar MCP（创建/搜索事件、suggest_time）
- 场景：自动约客户视频会议、发布日历排期、交付节点提醒
- 匹配度 ★★★★☆

6. Google Drive API — 文件柜｜资料读写
- 网址 https://developers.google.com/workspace/drive
- 注册：Google Cloud 项目启用 Drive API，OAuth 授权
- 额度：每项目 100 万 quota units/分钟，每用户 325,000/分钟，每项目每日出站 1 TB；Workspace 用户每日上传上限 750 GB；每日计费阈值详见官方页
- 用法：REST；files.list/create/get，支持分块上传
- Agent 适配：配合 Docs/Sheets API 做报价单、合同、素材归档
- 场景：把客户资料、产品图、剪辑素材自动归档到文件夹
- 匹配度 ★★★★☆

7. Cloudflare R2 — 仓库｜零出口费对象存储
- 网址 https://developers.cloudflare.com/r2
- 注册：Cloudflare 账号 → R2 → 创建存储桶（可能需绑支付方式，以控制台为准）
- 额度：每月免费 10 GB 存储、100 万次 Class A、1,000 万次 Class B 操作；出口流量免费
- 用法：S3 兼容 API（boto3、aws-sdk），或 Workers 绑定
- Agent 适配：Cloudflare 官方 MCP 服务器；预签名 URL 方便交付文件
- 场景：存放视频、产品图、PDF 报价，外发给客户不怕流量费
- 匹配度 ★★★★☆

8. Cloudflare Workers — 跑腿员｜免费无服务器函数
- 网址 https://developers.cloudflare.com/workers
- 注册：Cloudflare 账号即默认 Free 计划
- 额度：Free：每天 10 万请求、每次调用 10 毫秒 CPU；Workers KV 每天 10 万次读、1,000 次写，存 1 GB；日志每天 20 万事件保留 3 天
- 用法：wrangler CLI 部署 JS/TS，Webhook 接收与定时任务
- Agent 适配：可做 Agent 的 Webhook 入口、自建 MCP 服务器
- 场景：接 Stripe/Telegram/表单回调，触发你的 Agent 流程
- 匹配度 ★★★★★

9. AfterShip Tracking — 物流雷达｜多承运商追踪
- 网址 https://www.aftership.com/tracking ；文档 https://www.aftership.com/docs/tracking
- 注册：官网 Sign up；页面显示有 Free 计划
- 额度：Free 计划的具体单量以官方控制台为准；付费 Essentials $29/月含 6,000 单/年，超出 $0.08/单；API 与 Webhook 在 Premium（$59/月起，10 请求/秒）
- 用法：REST API 创建运单，自动识别承运商，Webhook 推送状态
- Agent 适配：支持 2,000+ 承运商与预计送达时间；Free 计划不含 API，需注意
- 场景：外贸发货后给客户发追踪页，减少「货到哪了」的询问
- 匹配度 ★★★☆☆

10. Stripe — 收银台｜全球收款
- 网址 https://stripe.com ；文档 https://docs.stripe.com
- 注册：邮箱注册，开通收款需验证身份与银行账户
- 额度：无开户费、无月费；按成功交易收费，美国国内卡 2.9% + 30¢，国际卡另加 1.5%，需货币转换另加 1%
- 用法：REST/SDK 创建 Checkout 链接与 Webhook
- Agent 适配：Webhook 驱动自动发货、开发票
- 场景：一人公司卖服务/课程/外贸样品，自动生成付款链接
- 匹配度 ★★★★☆

组合玩法：Gmail 收询盘 → Cloudflare Workers 接入口 → Stripe 出付款链接 → Google Drive/R2 归档合同与素材 → AfterShip 追踪发货 → Langfuse + Sentry 盯 Agent 表现 → PostHog 看转化
