# Vic API 精选 · 第 008 期 · 2026-11-14（周六）
主题：自动化连接器与出海工具箱——Slack、Make、Zapier 串流程，翻译、新闻、地图补外贸物流，网关与 Mistral 管模型
额度均于 2026-11-14 核对官方页面（未显示数字的写明以控制台为准）。

1. Slack API — 一人公司协作｜Agent 的通知中枢
- 网址 https://docs.slack.dev
- 注册：创建免费 Slack 工作区，在 api.slack.com/apps 新建 App 拿 Token
- 额度：官方限流页：发消息约每频道每秒 1 条；Web API 按方法分 Tier 1–4（每分钟 1+ / 20+ / 50+ / 100+ 次）；Events API 每小时 3 万次投递
- 用法：用 Bolt SDK 或 chat.postMessage / Incoming Webhook 发消息，Events API 收指令
- Agent 适配：官方文档含 Slack MCP Server 与 Agent 接入页，可直接接 Cursor、Claude 等
- 场景：订单与物流异常告警、内容日报、让 Agent 在频道里接任务
- 匹配度 ★★★★☆

2. Make — 自动化平台｜可视化连 1000+ 应用
- 网址 https://www.make.com
- 注册：make.com/register 免费注册
- 额度：定价页 FAQ：Free 计划每月 1000 credits，含 1 个数据存储（1MB）；多数动作消耗 1 credit
- 用法：拖拽搭建 Scenario，用 Webhook 触发，或调用其 REST API
- Agent 适配：页面提供官方 MCP server 与 AI agents 功能，可让外部 Agent 调用场景
- 场景：询盘自动入表、新单触发物流下单、内容多平台分发
- 匹配度 ★★★★☆

3. Zapier — 自动化平台｜海量应用一键打通
- 网址 https://zapier.com
- 注册：zapier.com 免费注册
- 额度：定价页：Free forever $0，含 Zaps、Tables、Forms，每月 100 tasks，两步 Zap
- 用法：在网页建 Zap，或用 Webhook / Zapier 的 Agent 与 Copilot
- Agent 适配：提供 Agents 与 Chatbots 产品，可把应用动作交给 AI 执行
- 场景：表单线索进 CRM、邮件摘要推送、社媒发布提醒
- 匹配度 ★★★☆☆

4. Google Cloud Translation — 外贸翻译｜多语种批量翻译
- 网址 https://cloud.google.com/translate
- 注册：Google Cloud 控制台启用 Translation API，需开通结算账号
- 额度：定价页：每月前 500,000 字符免费（以 10 美元月度抵扣体现），超出按 $20/百万字符起
- 用法：REST / 客户端库调用 translateText，支持批量与语言检测
- Agent 适配：有多语言官方 SDK，适合做 Agent 的翻译工具函数
- 场景：产品页多语言上架、询盘邮件互译、跨境客服
- 匹配度 ★★★★☆

5. NewsAPI — 新闻数据｜行业热点抓取
- 网址 https://newsapi.org
- 注册：newsapi.org 注册获取 API Key
- 额度：定价页：Developer 免费，每天 100 次请求，文章延迟 24 小时，可搜最近一个月，仅限开发用途
- 用法：GET /v2/everything 或 top-headlines，带 apiKey 参数
- Agent 适配：纯 REST + JSON，易包装成 Agent 搜索工具
- 场景：自媒体选题、外贸行业动态、竞品舆情
- 匹配度 ★★★☆☆

6. Vercel AI Gateway — 模型网关｜一个 Key 调多模型
- 网址 https://vercel.com/ai-gateway
- 注册：注册 Vercel 账号，在 AI Gateway 创建 Key
- 额度：定价页：免费层每月含 $5 额度，限 Free Tier 可用模型；付费层零加价
- 用法：用 AI SDK 或 OpenAI 兼容端点切换不同厂商模型
- Agent 适配：统一接口、支持自带 Key、可做用量报表，方便 Agent 做模型回退
- 场景：多模型降本、Agent 容灾切换、成本监控
- 匹配度 ★★★★☆

7. Google Maps Platform — 地图地理｜地址与路线
- 网址 https://developers.google.com/maps
- 注册：Google Cloud 控制台启用 Maps API，需开通结算账号
- 额度：定价页：按事件计费，各 SKU 有月度免费上限，例如 Dynamic Maps 每月 10,000 次免费；其余以官方控制台为准
- 用法：启用所需 API，生成 Key，调用 Geocoding / Routes / Places
- Agent 适配：官方文档含 Agent skills 与面向 AI 的资源页
- 场景：客户地址校验、仓库与配送距离、物流时效估算
- 匹配度 ★★★☆☆

8. Mapbox — 地图地理｜带 AI 工具的地理服务
- 网址 https://www.mapbox.com
- 注册：mapbox.com 免费注册拿 Token
- 额度：定价页称各产品有免费档（Navigation SDK 每月 10 个活跃用户免费）；API 具体数字以官方控制台为准
- 用法：用 Geocoding、Directions、Matrix API 的 REST 调用
- Agent 适配：定价页导航列有 Tools for agents（把位置能力带进 AI 工具）
- 场景：多点配送时间矩阵、地址解析、物流路线对比
- 匹配度 ★★★☆☆

9. Mistral API — AI 模型｜欧洲开源系大模型
- 网址 https://mistral.ai
- 注册：console.mistral.ai 注册，选择免费实验计划
- 额度：定价页显示 Free 计划，限额不公开数字，以官方控制台为准
- 用法：OpenAI 风格的 chat/completions 与 Python / JS SDK
- Agent 适配：支持函数调用与 Agents 接口，连接器 100+
- 场景：多语种文案、外贸邮件起草、低成本推理
- 匹配度 ★★★☆☆

10. Bitly — 短链分析｜追踪每次点击
- 网址 https://bitly.com
- 注册：bitly.com 免费注册，在开发者设置生成 Token
- 额度：定价页：Free 每月 5 条链接、2 个二维码、3 个自定义后缀，点击与扫码统计不限；接口额度以官方控制台为准
- 用法：POST /v4/shorten 创建短链，GET 取点击数据
- Agent 适配：REST + Token，适合做 Agent 的投放追踪工具
- 场景：自媒体各渠道引流对比、外贸目录二维码、邮件链接追踪
- 匹配度 ★★☆☆☆

组合玩法：NewsAPI 抓行业热点 → Mistral 起草多语文案 → Google Cloud Translation 出多语版 → Bitly 做追踪短链 → Make 分发 → Slack 推送日报
