# Vic API 精选 · 第 001 期 · 2026-11-06（周五）
主题：给 Agent 装上「大脑 + 眼睛 + 手」——一人公司起步必备的 10 个免费 API
额度均于 2026-11-06 核对官方页面。

1. Google Gemini API — 大脑｜AI 模型
- 网址 https://aistudio.google.com ；文档 https://ai.google.dev/gemini-api/docs
- 注册：Google 账号登录 AI Studio → Get API key → 自动建项目，免费层无需绑卡
- 额度：Free 层（活跃项目即可），按 RPM/TPM/RPD 计，按项目计算不按 Key；每日额度太平洋时间午夜重置；具体每模型限额在 AI Studio 的 Rate limit 页查看，以官方控制台为准
- 用法：POST generativelanguage.googleapis.com，或 google-genai SDK；支持 OpenAI 兼容端点
- Agent 适配：函数调用、结构化输出、长上下文、多模态（图/音/视频）
- 场景：外贸开发信撰写与多语种翻译、产品图识别、自媒体脚本
- 匹配度 ★★★★★

2. OpenRouter — 大脑路由器｜一个 Key 调几百个模型
- 网址 https://openrouter.ai ；文档 https://openrouter.ai/docs
- 注册：邮箱/Google/GitHub 登录 → Keys → Create Key
- 额度：模型 ID 以 :free 结尾的免费模型，20 次/分钟；累计充值不足 10 credits 时 50 次/天，≥10 时 1000 次/天
- 用法：OpenAI 兼容，base_url=https://openrouter.ai/api/v1
- Agent 适配：模型回退（fallback）、统一计费，接 Cline/Claude Code/n8n 都行
- 场景：同一任务对比多家模型，低成本跑批量
- 匹配度 ★★★★★

3. Groq — 极速推理｜毫秒级响应
- 网址 https://console.groq.com ；文档 https://console.groq.com/docs
- 注册：邮箱或 Google 登录 → API Keys
- 额度（免费计划）：openai/gpt-oss-120b 30 RPM、1K RPD、8K TPM、200K TPD；qwen3.8-27b 同级；whisper-large-v3 20 RPM、2K RPD、每小时 7.2K 音频秒
- 用法：OpenAI 兼容 https://api.groq.com/openai/v1
- Agent 适配：工具调用、内置浏览器搜索/代码执行、远程 MCP
- 场景：实时客服、语音转文字（会议/短视频字幕）
- 匹配度 ★★★★☆

4. Jina Reader — 眼睛｜任意网页转 Markdown
- 网址 https://jina.ai/reader
- 注册：免 Key 即可用；要更高额度在 jina.ai 领免费 Key（新 Key 送 1000 万 tokens）
- 额度：r.jina.ai 无 Key 20 RPM，免费 Key 500 RPM；s.jina.ai 搜索需 Key，100 RPM
- 用法：在网址前加 https://r.jina.ai/ ，例 curl https://r.jina.ai/https://example.com
- Agent 适配：官方 MCP mcp.jina.ai；支持 PDF、图片说明
- 场景：抓竞品页、读外贸客户官网、读论文 PDF 喂给模型
- 匹配度 ★★★★★

5. Tavily — 搜索｜为 Agent 设计的搜索 API
- 网址 https://tavily.com ；控制台 https://app.tavily.com
- 注册：登录即得 Key，无需信用卡
- 额度：每月 1000 credits；基础搜索 1 credit/次，高级 2；Extract 每 5 个网址 1 credit
- 用法：POST /search，Python/JS SDK
- Agent 适配：官方 MCP、Agent Skills、Claude Code/Cursor 集成
- 场景：选品调研、行业新闻追踪、客户背景调查
- 匹配度 ★★★★★

6. Firecrawl — 手｜整站爬取 + 结构化提取
- 网址 https://www.firecrawl.dev ；文档 https://docs.firecrawl.dev
- 注册：注册即得 Key，无需信用卡
- 额度：免费每月 1000 credits（约 1000 页或 500 次搜索），2 并发；scrape 10 次/分钟；Agent 每天 5 次免费
- 用法：POST /scrape /crawl /map /search；开源可自部署
- Agent 适配：MCP、JSON Schema 结构化提取
- 场景：批量抓 B2B 黄页做线索表、监控竞品价格
- 匹配度 ★★★★☆

7. Resend — 外联｜开发者邮件 API
- 网址 https://resend.com
- 注册：邮箱/GitHub 注册 → 验证发信域名（DKIM/SPF） → API Keys
- 额度：免费每月 3000 封，每天 100 封，3 个域名，3 个收件箱，1 个 webhook
- 用法：POST https://api.resend.com/emails，Node/Python SDK
- Agent 适配：收件箱支持 Agent 访问，可做自动收发
- 场景：外贸开发信、订单通知、自动回复（营销邮件需对方同意并带退订）
- 匹配度 ★★★★☆

8. Frankfurter — 汇率｜免 Key 开源汇率 API
- 网址 https://frankfurter.dev
- 注册：无需注册、无需 Key
- 额度：无月/日上限（仅防滥用限速），可商用；239 种货币、108 个央行和官方来源，数据可回溯到 1948 年
- 用法：curl https://api.frankfurter.dev/v2/rate/usd/cny
- Agent 适配：官方 MCP 与 llms.txt
- 场景：外贸报价自动换算、发票多币种、利润核算
- 匹配度 ★★★★☆

9. 17TRACK API — 物流｜全球包裹追踪
- 网址 https://api.17track.net ；文档 https://api.17track.net/en/doc
- 注册：注册 API 账号 → 获取 Key → 设置 Webhook
- 额度：2026-01-07 起，新账号一次性赠送 200 个单号（不再每月发放）；同一单号自动追踪不重复扣费
- 用法：先 register 注册单号，再 gettrackinfo 或 webhook 推送
- Agent 适配：webhook 推送状态给 Agent，自动通知客户
- 场景：跨境电商发货追踪、异常件提醒
- 匹配度 ★★★☆☆（额度有限，适合试跑）

10. Pexels API — 素材｜免费图片和视频
- 网址 https://www.pexels.com/api
- 注册：Pexels 账号 → 申请 API Key（即时下发）
- 额度：默认 200 次/小时、20000 次/月；按规范署名可申请无限
- 用法：Header Authorization: KEY，GET https://api.pexels.com/v1/search?query=...
- Agent 适配：自动给文章/短视频配图配 B-roll
- 场景：自媒体配图、产品页背景、短视频素材
- 注意：需显示 Pexels 链接与作者署名
- 匹配度 ★★★★☆

组合玩法：Tavily 找 → Jina/Firecrawl 读 → Gemini/Groq 想 → Resend 发 → Frankfurter 报价 → 17TRACK 追踪。
