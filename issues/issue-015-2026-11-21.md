# Vic API 精选 · 第 015 期 · 2026-11-21（周六）
主题：外贸合规背调与节假日排期，物流地址与天气，自媒体抠图与视频自动化，以及 Agent 的记忆、观测和向量库
额度均于 2026-11-21 核对官方页面。

1. GLEIF API — 外贸合规｜全球企业 LEI 身份库
- 网址 https://www.gleif.org/en/lei-data/gleif-api ；文档 https://api.gleif.org/docs
- 注册：无需注册，无需 Key，直接调用公开接口
- 额度：官方文档写明限流为每个用户每分钟 60 次请求，所有用户一致
- 用法：GET https://api.gleif.org/api/v1/lei-records?filter[entity.legalName]=公司名
- Agent 适配：REST + JSON，支持名称模糊搜索，可按 LEI 查母子公司股权关系
- 场景：Agent 在签约前核对海外买家的法定名称、注册地和母公司，补全背调
- 匹配度 ★★★★☆

2. OpenSanctions API — 外贸合规｜制裁名单与政要筛查
- 网址 https://www.opensanctions.org/api/ ；文档 https://www.opensanctions.org/docs/api/
- 注册：用企业邮箱在官网注册，获取 API Key
- 额度：官方页面写明注册即送 2,000 免费积分；之后按积分包购买，500 积分 €50；数据遵循 CC BY-NC 非商业许可，商用需另行授权
- 用法：POST https://api.opensanctions.org/match/default ，请求头 Authorization: ApiKey YOUR_API_KEY
- Agent 适配：REST + JSON，模糊匹配支持多语言和多文字，返回命中原因
- 场景：Agent 在接新客户询盘前筛查买家和收货人是否在制裁名单上，降低出口合规风险
- 匹配度 ★★★★☆

3. Calendarific — 外贸节假日｜全球公共假期日历
- 网址 https://calendarific.com/ ；定价 https://calendarific.com/pricing
- 注册：官网 Sign up for free 注册，获取 API Key
- 额度：免费档每月 500 次调用，需标注来源，社区支持，单一语言，历史和未来数据有限；付费年费 $500 档每月 50,000 次
- 用法：GET https://calendarific.com/api/v2/holidays?api_key=YOUR_API_KEY&country=US&year=2026
- Agent 适配：REST + JSON，按国家返回假期，适合做排期判断
- 场景：Agent 给海外客户排发货和跟进时间时，自动避开对方国家的公共假期和港口停工日
- 匹配度 ★★★☆☆

4. LocationIQ — 物流地址｜地址转坐标与路线
- 网址 https://locationiq.com/ ；定价 https://locationiq.com/pricing
- 注册：官网 Free sign up 注册，获取 Access Token
- 额度：免费档每天 5,000 次请求，每秒 2 次，每分钟 60 次，含地理编码、路线和静态地图，限有限商用；Developer 档 $100/月，每天 25,000 次
- 用法：GET https://us1.locationiq.com/v1/search?key=YOUR_API_KEY&q=地址&format=json
- Agent 适配：REST + JSON，全球地址解析，兼容 Nominatim 风格，容易接入
- 场景：Agent 把各国客户的收货地址统一成坐标，再用来估算运输路线和距离
- 匹配度 ★★★★☆

5. Tomorrow.io Weather API — 物流天气｜全球天气与MCP
- 网址 https://www.tomorrow.io/weather-api/ ；文档 https://docs.tomorrow.io/reference/welcome
- 注册：官网注册后在开发者后台获取 API Key
- 额度：官方限流文档写明按套餐限制每秒、每小时和每天的请求数，具体免费数字以官方控制台为准
- 用法：GET https://api.tomorrow.io/v4/weather/forecast?location=22.3,114.2&apikey=YOUR_API_KEY
- Agent 适配：REST + JSON，文档目录列出官方 Tomorrow.io MCP，Agent 可直接接入
- 场景：Agent 在发货前查询货运沿线的风雨和极端天气，提前预警延误
- 匹配度 ★★★☆☆

6. remove.bg — 自媒体素材｜一键抠图去背景
- 网址 https://www.remove.bg/api
- 注册：官网注册账号，在控制台获取 API Key
- 额度：官方 API 页面写明每月前 50 次调用免费；输出分辨率最高 50 百万像素
- 用法：POST https://api.remove.bg/v1.0/removebg ，请求头 X-Api-Key: YOUR_API_KEY，表单传 image_url
- Agent 适配：HTTP 接口简单，支持图片文件或链接上传，返回图片或 JSON
- 场景：Agent 批量处理产品图和人物图，生成适合多平台发布的素材
- 匹配度 ★★★★☆

7. Creatomate — 自媒体视频｜模板化视频与图片自动生成
- 网址 https://creatomate.com/ ；定价 https://creatomate.com/pricing
- 注册：官网 Start for free 注册，页面写明无需信用卡
- 额度：免费试用 50 个积分，含全部功能；Essential 档 $45/月，每月 2,000 积分
- 用法：POST https://api.creatomate.com/v1/renders ，请求头 Authorization: Bearer YOUR_API_KEY，传 template_id 和替换内容
- Agent 适配：REST + JSON，定位为媒体自动化平台，模板加变量即可批量出片
- 场景：Agent 把同一份文案套进模板，批量生成多语言短视频和封面图
- 匹配度 ★★★★☆

8. Letta — AI记忆｜有状态 Agent 与长期记忆
- 网址 https://www.letta.com/ ；定价 https://www.letta.com/pricing
- 注册：官网注册账号，获取 API Key；官方文档提供 Agent SDK
- 额度：Free 档 $0，最多 3 个有状态 Agent，每个记忆仓库 5 MiB 存储，可自带模型 Key；Pro 档 $20/月
- 用法：按官方 Agent SDK 快速入门创建 Agent，初始化客户端时填 YOUR_API_KEY
- Agent 适配：Agent 自带可编辑记忆，跨会话记住客户偏好和任务进度
- 场景：Agent 为每个长期客户保存沟通偏好、报价历史和待办，下次直接接上
- 匹配度 ★★★★☆

9. Pydantic Logfire — AI观测｜Agent 调用链与成本追踪
- 网址 https://pydantic.dev/logfire ；定价 https://pydantic.dev/pricing
- 注册：官网 Start free 注册，页面写明无需信用卡
- 额度：官方定价页写明每月 $20 免费用量（1,000 万条记录）；超出后 Team 和 Growth 档每百万条 $2
- 用法：pip install logfire 后调用 logfire.configure() ，用 YOUR_API_KEY 令牌上报
- Agent 适配：基于 OpenTelemetry，覆盖 AI 观测、评测和应用性能，可接多种框架
- 场景：Agent 长期运行时，查看每次工具调用的耗时和报错，定位卡点
- 匹配度 ★★★★☆

10. Zilliz Cloud — AI向量库｜托管 Milvus 向量检索
- 网址 https://zilliz.com/ ；定价 https://zilliz.com/pricing
- 注册：官网 Start for Free 注册，创建集群后获取 API Key
- 额度：Free 档 $0，含 5 GB 存储、每月 250 万 vCU、最多 5 个集合，社区支持
- 用法：pip install pymilvus 后用 MilvusClient(uri=集群地址, token="YOUR_API_KEY") 连接
- Agent 适配：兼容开源 Milvus，提供 Python SDK，适合做语义检索和知识库
- 场景：Agent 把产品手册、报价单和客户邮件向量化，回复询盘时检索最相关内容
- 匹配度 ★★★★☆
