# Vic API 精选 · 第 011 期 · 2026-11-17（周二）
主题：空运与欧盟合规、全球舆情、免费素材库，加上 Agent 的向量、提速模型和云端浏览器
额度均于 2026-11-17 核对官方页面。

1. VATcomply — 外贸合规｜欧盟增值税与汇率
- 网址 https://www.vatcomply.com ；接口 https://api.vatcomply.com
- 注册：无需注册，无需 Key
- 额度：无需 Key；按 IP 限速每秒 2 次请求
- 用法：GET https://api.vatcomply.com/vat?vat_number=BE0123456789 校验欧盟增值税号；/vat_rates 查各国税率；/rates 查欧洲央行汇率
- Agent 适配：纯 GET + JSON，Agent 可在报价或开票前自动校验欧盟客户税号
- 场景：向欧盟客户开发票前，让 Agent 校验对方 VAT 号并查当地税率
- 匹配度 ★★★★☆

2. Currency API (fawazahmed0) — 外贸汇率｜免限流汇率库
- 网址 https://github.com/fawazahmed0/exchange-api ；接口 https://cdn.jsdelivr.net/npm/@fawazahmed0/currency-api@latest/v1/currencies/usd.json
- 注册：无需注册，无需 Key
- 额度：官方 README 写明无请求限制，支持 200+ 币种，每日更新
- 用法：GET https://cdn.jsdelivr.net/npm/@fawazahmed0/currency-api@latest/v1/currencies/usd.json 返回以美元为基准的汇率；备用地址 https://latest.currency-api.pages.dev/v1/currencies/usd.json
- Agent 适配：静态 JSON，可按日期取历史汇率，代码里建议加备用地址回退
- 场景：多币种报价单、利润核算时让 Agent 批量换算
- 匹配度 ★★★★☆

3. GDELT DOC API — 外贸情报｜全球新闻舆情搜索
- 网址 https://blog.gdeltproject.org/gdelt-doc-2-0-api-debuts/ ；接口 https://api.gdeltproject.org/api/v2/doc/doc
- 注册：无需注册，无需 Key
- 额度：以官方控制台为准（官方文档未写明请求上限；检索窗口为最近 3 个月，单次最多 250 条）
- 用法：GET https://api.gdeltproject.org/api/v2/doc/doc?query=tariff&mode=artlist&format=json 返回相关新闻列表
- Agent 适配：JSON 输出，覆盖 65 种语言机器翻译，Agent 可直接做关键词监控
- 场景：监控目标市场的关税、港口罢工、政策新闻，生成每周外贸风险简报
- 匹配度 ★★★★☆

4. OpenSky Network API — 物流航空｜全球飞机实时位置
- 网址 https://openskynetwork.github.io/opensky-api/rest.html ；接口 https://opensky-network.org/api/states/all
- 注册：匿名可调用；登录后在账户页创建 API 客户端，用 OAuth2 取令牌可获更高额度
- 额度：匿名每天 400 积分；标准注册用户每天 4,000 积分；状态、轨迹、航班三类接口各自独立计额
- 用法：GET https://opensky-network.org/api/states/all?icao24=3c6444 查指定飞机当前状态
- Agent 适配：JSON 返回，注册档需 OAuth2 客户端凭证，令牌 30 分钟过期，Agent 需自动续期
- 场景：追踪空运货机位置，估算到港时间并自动通知客户
- 匹配度 ★★★☆☆

5. aviationstack — 物流航班｜航班状态与机场数据
- 网址 https://aviationstack.com/product ；注册 https://aviationstack.com/signup/free
- 注册：官网注册免费账号获取 Key
- 额度：免费版每月 100 次请求，仅限非商业用途；商业用途需付费版（Basic $49.99 每月，10,000 次）
- 用法：GET http://api.aviationstack.com/v1/flights?access_key=YOUR_API_KEY&flight_iata=CX880
- Agent 适配：REST + JSON，免费档额度小，适合低频查询和原型验证
- 场景：查询空运货班航班状态，核对延误后通知客户
- 匹配度 ★★★☆☆

6. GIPHY API — 自媒体素材｜全球最大 GIF 库
- 网址 https://developers.giphy.com/docs/api/ ；控制台 https://developers.giphy.com/dashboard/
- 注册：先在开发者控制台创建账号，再点 Create an API Key
- 额度：新建 Key 为 Beta，每小时限 100 次搜索或调用；需要更多须申请生产 Key
- 用法：GET https://api.giphy.com/v1/gifs/search?api_key=YOUR_API_KEY&q=cat&limit=5
- Agent 适配：REST + JSON；官方要求在客户端调用、不得缓存素材并需显示 Powered By GIPHY
- 场景：Agent 为社媒帖子匹配表情动图和话题梗图
- 匹配度 ★★★☆☆

7. Openverse API — 自媒体素材｜开放授权图片音频库
- 网址 https://docs.openverse.org/api/reference/index.html ；接口 https://api.openverse.org/v1/
- 注册：认证与限流规则见官方文档 Authentication and Throttling 页
- 额度：以官方控制台为准（本次核对的官方文档页未列出具体数字）
- 用法：GET https://api.openverse.org/v1/images/?q=sunset 搜索可开放授权的图片
- Agent 适配：返回每张素材的授权类型和署名信息，Agent 可自动生成署名文案
- 场景：为文章和视频找可商用或可二创的配图，并自动附上授权说明
- 匹配度 ★★★★☆

8. Voyage AI — AI向量｜嵌入与重排模型
- 网址 https://docs.voyageai.com/docs/pricing ；官网 https://www.voyageai.com
- 注册：官网注册后在控制台创建 API Key
- 额度：每个账号 voyage-4-large、voyage-4、voyage-4-lite 等前 2 亿 token 免费；voyage-finance-2 等前 5,000 万 token 免费；重排模型前 2 亿 token 免费；多模态前 2 亿文本 token 加 1,500 亿像素免费
- 用法：POST https://api.voyageai.com/v1/embeddings ，Header 带 Authorization: Bearer YOUR_API_KEY，body 里写 model 和 input
- Agent 适配：给 Agent 记忆和 RAG 做向量检索，配套 Python 客户端
- 场景：把客户邮件、产品资料向量化，让 Agent 按语义检索回复
- 匹配度 ★★★★★

9. SambaNova Cloud — AI模型｜高速推理 OpenAI 兼容
- 网址 https://docs.sambanova.ai/docs/en/models/rate-limits ；控制台 https://cloud.sambanova.ai
- 注册：官网注册账号，不绑支付方式即为免费档
- 额度：免费档每个模型（DeepSeek-V3.1、Meta-Llama-3.3-70B-Instruct、gpt-oss-120b）每分钟 20 次、每天 20 次、每天 20 万 token；绑支付方式后升级为开发者档
- 用法：用 OpenAI SDK，base_url 设为 https://api.sambanova.ai/v1 ，api_key 填 YOUR_API_KEY
- Agent 适配：官方文档标明 OpenAI 兼容，并支持函数调用与 JSON 模式
- 场景：给 Agent 加一个快速备用模型，处理批量摘要和分类
- 匹配度 ★★★★☆

10. Cloudflare Browser Run — AI抓取｜云端浏览器与网页转 Markdown
- 网址 https://developers.cloudflare.com/browser-rendering/platform/pricing/ ；文档 https://developers.cloudflare.com/browser-run/
- 注册：注册 Cloudflare 账号，在控制台创建 API 令牌
- 额度：Workers 免费版每天 10 分钟浏览器时间，最多 3 个并发浏览器；付费版每月含 10 小时，超出每小时 $0.09
- 用法：调用 /markdown、/screenshot、/pdf、/scrape、/json 等 Quick Actions 接口，认证用 Authorization: Bearer YOUR_API_KEY
- Agent 适配：官方提供 MCP 服务器，并支持 Puppeteer、Playwright、Stagehand
- 场景：让 Agent 抓取需要渲染的商家官网，转 Markdown 后做背调
- 匹配度 ★★★★★
