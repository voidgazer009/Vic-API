# Vic API 精选 · 第 002 期 · 2026-11-08（周日）
主题：给 Agent 接上「工具箱 + 业务线」——外贸、物流、自媒体一条龙的 10 个免费 API
额度均于 2026-11-08 核对官方页面。

1. Cloudflare Workers AI — 边缘推理｜每日免费推理
- 网址 https://developers.cloudflare.com/workers-ai ；定价 https://developers.cloudflare.com/workers-ai/platform/pricing/
- 注册：Cloudflare 账号（免费 Workers 计划即可）→ 控制台 AI → Workers AI → 创建 API Token，记下 Account ID
- 额度：免费 10,000 Neurons/天，每天 00:00 UTC 重置；超出需 Workers Paid，$0.011/1,000 Neurons。部分新模型（如 Kimi K2.6、GLM 5.x、DeepSeek V4）需付费方式才能调用
- 用法：OpenAI 兼容端点 https://api.cloudflare.com/client/v4/accounts/{ACCOUNT_ID}/ai/v1 ，或 Workers 里 env.AI.run()
- Agent 适配：函数调用、JSON 模式、官方 MCP 服务器与 Agents SDK；同时有 LLM、向量、Whisper 语音、FLUX 绘图
- 场景：便宜的批量文本分类/摘要、给知识库做向量、短视频语音转字幕
- 匹配度 ★★★★☆

2. Exa — 语义搜索｜为 AI 设计的搜索引擎
- 网址 https://exa.ai ；定价 https://exa.ai/pricing
- 注册：dashboard.exa.ai 登录即得 Key，无需付款方式
- 额度：Starter 免费，每月 $10 credits + 注册送 $10；10 QPS 搜索。按量价：Lite 搜索 $4/千次、Contents $1/千页，免费额度约够每月 2000 次 Lite 搜索
- 用法：POST https://api.exa.ai/search ，Python/JS SDK；支持人物、公司、学术专用索引
- Agent 适配：官方 MCP、Claude Connector、ChatGPT 插件、50+ 集成
- 场景：按描述找潜在客户公司、找同类竞品、追踪行业新闻
- 匹配度 ★★★★★

3. Composio — Agent 工具箱｜一个接口连千个 App
- 网址 https://composio.dev ；定价 https://composio.dev/pricing
- 注册：dashboard.composio.dev 注册，Hobby 计划无需信用卡
- 额度：Hobby $0，每月 100,000 次工具调用、50,000 次触发器、3 个成员、送 $2 credits；托管 App 前 1,000 个连接账号免费；到上限即停，不会意外扣费
- 用法：pip install composio ，用 Session 给 Agent 加载 Gmail、Slack、Notion、Sheets 等工具
- Agent 适配：MCP、OAuth 托管、工具搜索（元工具不计费），接 OpenAI/Claude/LangChain
- 场景：让 Agent 直接发 Gmail、写表格、建日程，不用自己写 OAuth
- 匹配度 ★★★★★

4. DeepL API — 外贸翻译｜商务级多语种
- 网址 https://www.deepl.com/pro-api ；文档 https://developers.deepl.com
- 注册：DeepL 官网选 API 计划注册（已有网页版账号需另建账号）→ 账户页拿 API Key
- 额度：新用户为 API Developer 计划，免费累计 1,000,000 字符，用完不重置，需升级 Growth；旧 API Free（每月 50 万字符）已停止新购。免费计划单文档最大 10 MB
- 用法：POST /v2/translate ，Header Authorization: DeepL-Auth-Key KEY；官方 Python/Node/Java 等 SDK
- Agent 适配：已上线 MCP（Copilot/ChatGPT/Claude），支持术语表、正式/非正式语气
- 场景：开发信与询盘回复多语种、产品说明书 PDF/Word 整篇翻译
- 匹配度 ★★★★☆（免费额度一次性，适合起步）

5. UN Comtrade — 外贸数据｜联合国全球进出口统计
- 网址 https://comtradeplus.un.org ；说明 https://uncomtrade.org/docs/subscriptions
- 注册：免费注册 UN Comtrade 账号 → My Comtrade → My API portal 申请免费订阅 Key
- 额度：免费 Basic 账号 500 次/天，每次最多 10 万条记录，限速 5 次/秒；不注册的 preview 接口每次 500 条、1 次/秒
- 用法：GET https://comtradeapi.un.org/data/v1/get/C/A/HS ，按 HS 编码、国家、年份查询；有 Python/R 库
- Agent 适配：结构化 JSON，适合让 Agent 自动出「某产品主要进口国」报告
- 场景：选品与目标市场分析、按 HS 编码看各国进口额和趋势
- 匹配度 ★★★★☆

6. openrouteservice — 物流｜路线与配送优化
- 网址 https://openrouteservice.org ；套餐 https://openrouteservice.org/plans/
- 注册：HeiGIT 账号注册 → 控制台生成 Key（Standard 计划免费）
- 额度：Standard 免费计划（每天/每分钟）路线 2000/40、距离矩阵 500/40、等时圈 500/20、地理编码 3000/100、路线优化 500/40；也可自部署无上限
- 用法：GET https://api.openrouteservice.org/v2/directions/driving-car?api_key=KEY&start=…&end=…
- Agent 适配：开源（基于 OpenStreetMap），Python 库 openrouteservice-py
- 场景：本地配送排线、仓库到客户的时效和成本估算、门店覆盖范围
- 匹配度 ★★★★☆

7. YouTube Data API — 自媒体｜选题与数据分析
- 网址 https://developers.google.com/youtube/v3 ；配额说明 https://developers.google.com/youtube/v3/getting-started
- 注册：Google Cloud 控制台建项目 → 启用 YouTube Data API v3 → 创建 API Key（上传/评论需 OAuth）
- 额度：默认每天 100 次 search.list、100 次 videos.insert，其余接口合计 10,000 单位/天；读取一般 1 单位，写入一般 50 单位；可申请提额
- 用法：GET https://www.googleapis.com/youtube/v3/search?part=snippet&q=…&key=KEY
- Agent 适配：官方各语言客户端库，Agent 可自动拉热门视频、标题、评论做分析
- 场景：找爆款选题、分析竞品频道、自动上传视频和设缩略图
- 匹配度 ★★★★☆

8. ElevenLabs — 自媒体｜AI 配音与语音转文字
- 网址 https://elevenlabs.io ；API 定价 https://elevenlabs.io/pricing/api
- 注册：邮箱/Google 注册 → Developers → API Keys
- 额度：Free 计划每月含 TTS v4 10,000 字符（约 10 分钟）或 Flash/Turbo 20,000 字符；Scribe v2 语音转文字 4 小时 30 分钟；音效 8 次生成
- 用法：POST https://api.elevenlabs.io/v1/text-to-speech/{voice_id} ，Python/JS SDK
- Agent 适配：90+ 语言、实时低延迟模型，可做语音 Agent
- 场景：短视频配音、多语种口播、播客和会议转写
- 匹配度 ★★★★☆（免费额度少，适合试样）

9. Notion API — 一人公司｜Agent 的数据库与知识库
- 网址 https://developers.notion.com ；限额 https://developers.notion.com/reference/request-limits
- 注册：notion.so/developers 新建 Integration → 拿 Token → 在页面里把该 Integration 加入
- 额度：API 免费；非 Business/Enterprise 工作区每个连接 180 次/分钟（平均 3 次/秒），查询数据源约 3 次/秒；单次请求最多 1000 个块、500KB
- 用法：POST https://api.notion.com/v1/pages ，官方 JS SDK 自动重试 429
- Agent 适配：官方 MCP、Webhooks、Agents 接口
- 场景：Agent 自动写客户 CRM、内容日历、订单台账，人看 Notion 就行
- 匹配度 ★★★★★

10. Telegram Bot API — 一人公司｜免费通知与客服机器人
- 网址 https://core.telegram.org/bots/api ；FAQ https://core.telegram.org/bots/faq
- 注册：在 Telegram 找 @BotFather → /newbot → 拿到 Bot Token
- 额度：免费；单聊约 1 条/秒，群里 20 条/分钟，群发约 30 条/秒；发文件最大 50 MB，下载最大 20 MB
- 用法：POST https://api.telegram.org/bot{TOKEN}/sendMessage ，Webhook 或长轮询收消息
- Agent 适配：Agent 的手机遥控器：推送日报、审批按钮、接收语音和图片
- 场景：订单/物流异常提醒、每日数据播报、海外客户客服
- 匹配度 ★★★★☆
