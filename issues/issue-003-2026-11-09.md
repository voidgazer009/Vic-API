# Vic API 精选 · 第 003 期 · 2026-11-09（周一）
主题：给 Agent 装上「眼睛和后台」——搜索、获客、数据与自媒体的 10 个免费 API
额度均于 2026-11-09 核对官方页面。

1. Apify — 爬取平台｜上万个现成爬虫，一键调用
- 网址 https://apify.com ；定价 https://apify.com/pricing ；MCP 文档 https://docs.apify.com/platform/integrations/mcp
- 注册：apify.com 邮箱/Google/GitHub 注册，Free 计划无需信用卡 → Console → Settings → API tokens
- 额度：Free 每月含 $5 平台额度（可用于 Apify Store 里的 Actor 或自己的 Actor）；计算单元 $0.2/CU；最多 5 个并发运行
- 用法：在 Apify Store 选 Actor（如网站内容抓取、Google 地图、社媒数据），REST 调用 POST https://api.apify.com/v2/acts/{actorId}/runs ，或用 JS/Python 客户端
- Agent 适配：官方 MCP 服务器 mcp.apify.com ，Agent 可自行搜索并运行 Actor；另有 Agent Skills 和插件
- 场景：抓海外买家/竞品店铺、采集同行爆款内容、给 RAG 知识库批量爬网页
- 匹配度 ★★★★★

2. Brave Search API — 搜索｜Agent 专用搜索
- 网址 https://brave.com/search/api ；定价 https://api-dashboard.search.brave.com/documentation/pricing
- 注册：api-dashboard.search.brave.com 注册 → 订阅 Search 计划 → 生成 API Key（是否需绑定支付方式以注册页为准）
- 额度：Search 计划每月含 $5 免费额度，按 $5/千次请求计，约合 1,000 次；容量 50 次/秒。Answers 另计 $4/千次查询 + token 费
- 用法：GET https://api.search.brave.com/res/v1/web/search?q=关键词 ，请求头带 X-Subscription-Token ；LLM Context 接口直接返回适合喂给模型的片段
- Agent 适配：提供 LLM Context（给 Agent 的搜索结果）、Answers（带引用答案）、新闻/图片/视频/地点搜索；官方有 MCP 服务器（GitHub brave/brave-search-mcp-server）
- 场景：Agent 联网查行业新闻、核对客户公司信息、给自媒体选题找热点
- 匹配度 ★★★★☆

3. Hunter — 外贸获客｜按域名找到决策人邮箱
- 网址 https://hunter.io ；定价 https://hunter.io/pricing ；API 文档 https://hunter.io/api-documentation ；MCP https://hunter.io/mcp
- 注册：hunter.io 邮箱注册 → Dashboard → API 页面获取免费 API Key
- 额度：Free 每月 50 credits；找到 1 个邮箱用 1 credit（没找到不扣），验证 1 个邮箱用 0.5 credit；Discover AI 搜索每月 30 次；每个序列最多 500 收件人
- 用法：GET https://api.hunter.io/v2/domain-search?domain=example.com&api_key=KEY ；另有 Email Finder、Email Verifier
- Agent 适配：官方 MCP 服务器，可让 Claude/ChatGPT 等直接调用 Hunter 找人找邮箱；有 Google Sheets 插件
- 场景：拿到海外买家官网域名后，自动找采购负责人邮箱并验证，再接入开发信
- 匹配度 ★★★★☆（每月仅 50 credits，适合精准小批量）

4. REST Countries — 外贸数据｜国家币种区号速查
- 网址 https://restcountries.com ；定价 https://restcountries.com/pricing
- 注册：restcountries.com 点 Get an API key → 邮箱注册（免费，无需信用卡）→ 建 Key
- 额度：Free $0，每月 1,000 次请求、2 个 API Key、数据每 24 小时同步；页面注明所有计划支持商用，并含全部接口和字段
- 用法：GET https://api.restcountries.com/countries/v5/codes.alpha_2/CA ，请求头 Authorization: Bearer {KEY} ；可用 ?response_fields= 只取需要的字段
- Agent 适配：JSON 结构化、字段可裁剪，省 token；覆盖 250+ 国家、90+ 字段（币种、语言、国家区号、时区、边界等）
- 场景：Agent 写开发信时自动匹配客户国家的语言、币种和时区；报价单自动带当地货币
- 匹配度 ★★★★☆

5. Nager.Date — 外贸日历｜200+ 国家公共假期，免 Key
- 网址 https://date.nager.at/Api ；GitHub https://github.com/nager/Nager.Date
- 注册：无需注册、无需 Key
- 额度：页面标注 200+ 国家、无速率限制（No Rate Limits）、支持 CORS；开源项目，可在 GitHub 自托管
- 用法：GET https://nagerholidays.com/api/v4/Holidays/{国家代码}/{年份} ，如 /api/v4/Holidays/AT/2026
- Agent 适配：纯 JSON，返回日期、名称、是否全国假日、假日类型；Agent 一个函数就能调
- 场景：开发信避开客户国家的假期；排发货、清关和付款提醒时避开休息日
- 匹配度 ★★★☆☆（简单但很实用）

6. Open-Meteo — 物流天气｜免 Key 天气与海运预报
- 网址 https://open-meteo.com ；定价/限额 https://open-meteo.com/en/pricing ；文档 https://open-meteo.com/en/docs
- 注册：免费版无需注册、无需 Key
- 额度：免费版仅限非商业用途，600 次/分钟、5,000 次/小时、10,000 次/天、300,000 次/月，无可用性保证；商用需订阅（Standard 100 万次/月）；数据需署名（CC BY 4.0）
- 用法：GET https://api.open-meteo.com/v1/forecast?latitude=22.3&longitude=114.2&hourly=temperature_2m,precipitation ；另有 Marine、Air Quality、Geocoding、Flood 接口
- Agent 适配：30+ 天气模型、纯 JSON；自带地名转坐标的 Geocoding API，Agent 可直接按城市名查
- 场景：判断港口/航线天气是否影响出货；给跨境卖家做发货延误预警
- 匹配度 ★★★☆☆（正式商用请改用付费版）

7. Cohere — AI 模型｜Rerank 提升 RAG
- 网址 https://cohere.com ；限额 https://docs.cohere.com/docs/rate-limits
- 注册：dashboard.cohere.com 注册 → API keys 页面创建 Trial（评估）Key
- 额度：Trial Key 免费但有限：每月 1,000 次 API 调用；Chat 各模型 20 次/分钟；Embed 2,000 条输入/分钟；Rerank 10 次/分钟；语音转写 5 次/分钟；生产用需付费 Key
- 用法：Python/JS SDK 或 POST https://api.cohere.com/v2/rerank 、/v2/embed 、/v2/chat
- Agent 适配：Chat 支持工具调用与 RAG 引用；Rerank 可对搜索结果二次排序；Embed 做语义检索；有 LangChain、LlamaIndex 集成，也可经 OpenRouter 调用
- 场景：Brave/Exa 搜出一堆结果后用 Rerank 选最相关 5 条；给客户问答库做向量检索
- 匹配度 ★★★★☆（1000 次/月适合评估和小项目）

8. Unsplash API — 自媒体素材｜高质量免版权图库
- 网址 https://unsplash.com/developers ；文档 https://unsplash.com/documentation
- 注册：unsplash.com 注册开发者账号 → Your apps → New Application 拿 Access Key
- 额度：新应用为 Demo 模式，50 次请求/小时；申请 Production 获批后 1,000 次/小时；只统计 api.unsplash.com 的 JSON 请求，图片文件请求不计；使用须按规范标注摄影师和 Unsplash
- 用法：GET https://api.unsplash.com/search/photos?query=logistics ，头部 Authorization: Client-ID {AccessKey}
- Agent 适配：官方 SDK，响应带动态裁剪参数（宽高、格式）和 BlurHash；返回摄影师信息便于自动署名
- 场景：Agent 写完文章/公众号自动配图；给产品页和社媒帖找背景图
- 匹配度 ★★★☆☆（与 Pexels 互补）

9. AssemblyAI — 自媒体转写｜语音转文字，附带说话人分离
- 网址 https://www.assemblyai.com ；定价 https://www.assemblyai.com/pricing
- 注册：assemblyai.com 注册即可开始转写，无需信用卡 → Dashboard 拿 API Key
- 额度：免费层含最多 185 小时预录音频转写 + 最多 333 小时实时转写；之后按量：Universal-2 $0.15/小时、Universal-3.5 Pro $0.21/小时；说话人分离 +$0.02/小时；免费计划实时连接每分钟最多新开 5 个
- 用法：Python/JS SDK，或上传音频 URL 到 POST https://api.assemblyai.com/v2/transcript 后轮询结果
- Agent 适配：99 种语言（Universal-2）、说话人分离、关键词提示；同平台还有文字转语音（$15/百万字符）
- 场景：把客户会议、播客和视频自动转成文字稿，再让 Agent 提炼成文章、短视频脚本
- 匹配度 ★★★★☆

10. Supabase — 一人公司后端｜Agent 直连的后端
- 网址 https://supabase.com ；定价 https://supabase.com/pricing ；MCP 文档 https://supabase.com/docs/guides/getting-started/mcp
- 注册：supabase.com 用 GitHub 登录 → New project（免费计划可建 2 个项目）
- 额度：Free 计划 $0/月：API 请求不限、5 万月活用户、500 MB 数据库、1 GB 文件存储、5 GB 出口流量、Realtime 200 并发连接 / 每月 200 万条消息；项目闲置 1 周会被暂停；无自动备份
- 用法：supabase-js / Python 客户端，或 REST 自动生成 https://{project}.supabase.co/rest/v1/{table}
- Agent 适配：官方 MCP 服务器（文档 2026-11-06 更新），可让 AI 查询和管理你的项目；支持向量/Embeddings；官方提示连接有安全风险，建议只连开发项目
- 场景：给 Agent 做 CRM、订单库、知识库向量检索和会员登录，不用自己搭服务器
- 匹配度 ★★★★★
