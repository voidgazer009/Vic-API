# Vic API 精选 · 第 014 期 · 2026-11-20（周五）
主题：英国企业背调与汇率、物流地址与天气，加上视频转写，以及 Agent 的观测、数据库和向量记忆
额度均于 2026-11-20 核对官方页面。

1. Companies House API — 外贸企业背调｜英国公司官方登记
- 网址 https://developer-specs.company-information.service.gov.uk/ ；开发者中心 https://developer.company-information.service.gov.uk/
- 注册：在 Companies House 开发者中心注册账号，创建 API Key 类型的应用即可获得密钥
- 额度：官方限流指南写明每个应用每五分钟窗口最多 600 次请求；需要更高额度可联系官方申请
- 用法：GET https://api.company-information.service.gov.uk/search/companies?q=公司名 ，用 YOUR_API_KEY 作为基本认证的用户名
- Agent 适配：REST + JSON，可查公司状态、董事、注册地址，适合做英国买家的自动背调
- 场景：Agent 收到英国客户询盘后，先核实公司是否真实存在、是否仍在营业
- 匹配度 ★★★★☆

2. currencylayer — 外贸汇率｜轻量汇率与历史价
- 网址 https://currencylayer.com/product ；文档 https://currencylayer.com/documentation
- 注册：官网点 Get Free API Key，邮箱注册后获得 Access Key
- 额度：免费版页面写明 100 次 API 调用、每日更新、含历史汇率、仅限非商业使用；商业使用需付费 Basic 档（$14.99/月，最多 10,000 次请求）
- 用法：GET https://api.currencylayer.com/live?access_key=YOUR_API_KEY&currencies=EUR,GBP,CNY
- Agent 适配：REST + JSON，一次返回多币种；免费额度小，适合给 Agent 做每日汇率快照
- 场景：Agent 生成外贸报价单时，按当天汇率换算多币种价格
- 匹配度 ★★★☆☆

3. Geocodio — 物流地址解析｜批量地址转坐标
- 网址 https://www.geocod.io/ ；定价 https://www.geocod.io/pricing/
- 注册：官网点 Start for free 注册即可拿到 API Key，无需信用卡信息以官方页面为准
- 额度：按量付费档每天 2,500 次查询免费，页面写明「forever」；覆盖北美、澳洲、新西兰，并支持英国地理编码
- 用法：GET https://api.geocod.io/v1.7/geocode?q=1109+N+Highland+St+Arlington+VA&api_key=YOUR_API_KEY
- Agent 适配：REST + JSON，支持批量地址，适合 Agent 清洗货运地址
- 场景：Agent 在发货前批量校验和标准化北美收货地址，降低退件率
- 匹配度 ★★★★☆

4. National Weather Service API — 物流天气｜美国官方天气
- 网址 https://www.weather.gov/documentation/services-web-api ；接口 https://api.weather.gov/
- 注册：无需注册，无需 Key，请求时需带自定义 User-Agent 标识
- 额度：官方页面写明免费、可用于任何用途；限流数字不公开，页面称对常规使用「足够宽松」，超限会报错并通常在约 5 秒后可重试
- 用法：先 GET https://api.weather.gov/points/38.8894,-77.0352 取得网格，再请求返回的 forecast 地址
- Agent 适配：开放数据、REST + JSON，无需密钥，Agent 可直接调用
- 场景：Agent 为美国港口和内陆运输提前预警暴风雪、飓风等天气延误
- 匹配度 ★★★☆☆

5. Stormglass — 物流海运天气｜全球海浪与风速
- 网址 https://stormglass.io/ ；定价 https://stormglass.io/pricing/
- 注册：官网点 Try for free 注册后在控制台获得 API Key
- 额度：免费档每天 10 次请求，含全部天气参数，不提供支持，且不可商用；付费 Small 档 €19/月，每天 500 次
- 用法：GET https://api.stormglass.io/v2/weather/point?lat=22.3&lng=114.2&params=waveHeight,windSpeed ，请求头 Authorization: YOUR_API_KEY
- Agent 适配：REST + JSON，适合按航线坐标查浪高风速；免费次数少，只宜做个人测试
- 场景：Agent 评估海运航线上的海况，辅助判断船期是否可能延误
- 匹配度 ★★★☆☆

6. Supadata — 自媒体转写｜视频链接直出文字稿
- 网址 https://supadata.ai/ ；定价 https://supadata.ai/pricing
- 注册：官网 Sign Up 注册，在控制台获取 API Key
- 额度：免费档每月 100 积分，速率每秒 1 次；付费 Basic 档 300 积分每月 $5（按年付）
- 用法：GET https://api.supadata.ai/v1/transcript?url=视频链接 ，请求头 x-api-key: YOUR_API_KEY
- Agent 适配：REST + JSON，输入视频链接即可拿文字稿，方便 Agent 做二次创作
- 场景：Agent 抓取同行爆款视频的文字稿，提炼选题再改写成多语言脚本
- 匹配度 ★★★★☆

7. Gladia — 自媒体语音转写｜多语言转写与说话人分离
- 网址 https://www.gladia.io/ ；定价 https://www.gladia.io/pricing
- 注册：官网注册账号，在控制台获取 API Key
- 额度：自助档页面写明新用户送 €50 免费额度；之后按量付费，异步转写起价每小时 €0.16；支持 100 多种语言和说话人分离
- 用法：先 POST https://api.gladia.io/v2/upload 上传音频，再 POST https://api.gladia.io/v2/pre-recorded 发起转写，请求头 x-gladia-key: YOUR_API_KEY
- Agent 适配：REST + JSON，异步任务模式，适合批量处理访谈和播客
- 场景：Agent 把多语言采访音频转成字幕和文字稿，用于全球账号发布
- 匹配度 ★★★★☆

8. Helicone — AI观测｜给模型调用加日志和成本统计
- 网址 https://www.helicone.ai/ ；定价 https://www.helicone.ai/pricing
- 注册：官网 Get started for free 注册，在控制台创建 Helicone Key
- 额度：Hobby 免费档含 10,000 次免费请求、1 GB 存储、1 个席位和 1 个组织；Pro 档 $79/月
- 用法：按官方文档把 OpenAI 兼容客户端的 base URL 指向 Helicone 网关，并加请求头 Helicone-Auth: Bearer YOUR_API_KEY
- Agent 适配：兼容 OpenAI 风格调用，只改网关地址就能记录每次请求、延迟和成本
- 场景：Agent 长期运行时，查看哪些任务最耗 token，及时优化提示词
- 匹配度 ★★★★☆

9. Turso — AI数据库｜给每个 Agent 一个 SQLite 数据库
- 网址 https://turso.tech/ ；定价 https://turso.tech/pricing
- 注册：官网 Try Cloud free 注册，页面写明免费起步无需信用卡
- 额度：Free 档每月 $0，含 100 个数据库、5 GB 存储、每月 5 亿行读取、1000 万行写入、3 GB 同步数据
- 用法：安装官方 Turso CLI 后执行 turso db create my-agent-db ，用 libSQL SDK 并携带 YOUR_API_KEY 令牌连接
- Agent 适配：页面主打「每个 Agent 一个独立数据库」，SQL 接口，适合存任务状态和客户记录
- 场景：Agent 为每个客户或每条业务线建独立数据库，保存询盘、报价和跟进记录
- 匹配度 ★★★★☆

10. Chroma Cloud — AI记忆｜向量与全文检索云服务
- 网址 https://www.trychroma.com/ ；定价 https://www.trychroma.com/pricing
- 注册：官网 Get started for free 注册，创建数据库后获得 API Key
- 额度：Starter 档每月 $0 并附 $5 免费额度；超出后按量计费，写入每 GiB $2.50，存储每 GiB 每月 $0.33
- 用法：pip install chromadb 后用 chromadb.CloudClient 连接，参数填 YOUR_API_KEY、租户和数据库名
- Agent 适配：开源 Chroma 的云版，支持向量、全文和元数据检索，可做 Agent 长期记忆
- 场景：Agent 把产品手册和历史邮件存成向量库，回复客户时检索相关内容
- 匹配度 ★★★★☆
