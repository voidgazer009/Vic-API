# Vic API 精选 · 第 006 期 · 2026-11-12（周四）
主题：让 Agent 会发邮件、会推送、会查表——邮件外联、搜索、通知与数据库 API 精选
额度均于 2026-11-12 核对官方页面（未显示数字的写明以控制台为准）。

1. Postmark — 邮件外联｜事务邮件高送达
- 网址 https://postmarkapp.com
- 注册：官网 Start free trial 注册，无需信用卡；新账号默认 Free 开发者计划
- 额度：定价页：Free $0/月，每月 100 封，不过期、不允许超额；付费 Basic $15/月起 1 万封
- 用法：REST API 或 SMTP 发信，官方有 SDK，沙盒模式可测试
- Agent 适配：REST + JSON，Agent 一次 HTTP 调用即可发报价/跟进邮件；官方提供 Postmark Skills 教 Agent 发信
- 场景：外贸询盘自动回复、订单确认、物流通知邮件
- 匹配度 ★★★★☆

2. SearchApi — 搜索｜多引擎实时 SERP
- 网址 https://www.searchapi.io
- 注册：官网 Sign up，无需信用卡
- 额度：定价页：注册送 100 次免费请求；付费 Developer $40/月含 1 万次；失败请求不计费
- 用法：GET 请求带 api_key 和 engine 参数，返回结构化 JSON
- Agent 适配：覆盖 Google、Bing、Amazon、YouTube、TikTok、LinkedIn Jobs 等引擎，Agent 可当万能搜索工具
- 场景：外贸竞品价格监控、选品调研、自媒体热点与关键词研究
- 匹配度 ★★★★☆

3. Pushover — 推送通知｜手机即时推送
- 网址 https://www.pushover.net
- 注册：官网注册账号，在 iOS/Android 安装 App（30 天免费试用，之后为一次性购买）
- 额度：官网：每位用户每月可免费发送最多 10,000 条消息
- 用法：POST https://api.pushover.net/1/messages.json，带 token、user、message
- Agent 适配：一条 HTTP 请求即可让 Agent 把结果、告警推到手机
- 场景：Agent 任务完成提醒、订单/货件异常告警、每日汇总推送
- 匹配度 ★★★★☆

4. Google Sheets API — 一人公司效率｜表格当数据库
- 网址 https://developers.google.com/sheets/api
- 注册：在 Google Cloud 控制台建项目并启用 Sheets API，OAuth 或服务账号授权
- 额度：官方限额页：读请求每分钟每项目 300 次、每用户每项目 60 次；写请求同样 300/60
- 用法：REST 或官方各语言客户端，读写单元格、追加行
- Agent 适配：官方已提供 Sheets MCP server；Agent 可直接读写 CRM、报价表、选题库
- 场景：线索表自动追加、报价单生成、内容排期表同步
- 匹配度 ★★★★★

5. ipapi.co — 外贸IP定位｜IP 查国家时区币种
- 网址 https://ipapi.co
- 注册：免费层直接调用，无需注册
- 额度：定价页：Free 每月 30,000 次、每天最多 1,000 次，仅适合测试/开发，非生产使用，无支持
- 用法：GET https://ipapi.co/{ip}/json/ 返回国家、城市、时区、币种
- Agent 适配：单次 GET 返回 JSON，Agent 可据访客 IP 自动匹配语言、币种
- 场景：独立站访客国家识别、询盘来源分析、自动选择报价币种
- 匹配度 ★★★☆☆

6. Abstract VAT API — 外贸合规｜欧盟 VAT 号验证
- 网址 https://www.abstractapi.com/api/vat-validation-rates-api
- 注册：官网 get free api key，无需信用卡
- 额度：定价页：Free $0，100 次请求、每秒 1 次；Standard $99/月
- 用法：GET 请求带 api_key 和 vat_number，返回有效性与税率
- Agent 适配：REST + JSON，Agent 在开单前自动核验欧洲客户 VAT 号
- 场景：出口欧盟前验证客户资质、自动取目标国税率报价
- 匹配度 ★★★★☆

7. Mailtrap — 邮件测试与发送｜邮件沙盒加发信
- 网址 https://mailtrap.io
- 注册：官网 Start for Free 注册
- 额度：定价页：Free $0/月，最多 4,000 封，每天 150 封，1 个域名，日志保留 3 天
- 用法：API 或 SMTP 发信；沙盒捕获测试邮件，不会误发客户
- Agent 适配：定价页标注面向 AI Agent；Agent 可先沙盒预演再正式发送
- 场景：外联邮件上线前预演、批量开发信小规模发送
- 匹配度 ★★★☆☆

8. Discord API — 自媒体社群｜社群机器人与 Webhook
- 网址 https://discord.com/developers/docs
- 注册：Developer Portal 创建 Application 获取 Bot Token，或在频道设置创建 Webhook
- 额度：官方限速文档：按路由与全局限速，具体数字以响应头 X-RateLimit 与官方控制台为准
- 用法：Webhook 一次 POST 发消息；Bot 用 discord.js 等 SDK
- Agent 适配：Agent 可做社群客服、发布提醒、读取反馈
- 场景：粉丝社群自动答疑、内容更新推送、订单通知频道
- 匹配度 ★★★☆☆

9. Airtable API — 一人公司效率｜可视化数据库
- 网址 https://airtable.com/developers/web/api/introduction
- 注册：官网 Sign up for free，创建 Base 后生成个人访问令牌
- 额度：官方定价页确认有 Free 免费计划，具体记录数与调用额度以官方控制台为准
- 用法：REST API 增删改查记录，带 Bearer 令牌
- Agent 适配：REST + JSON，Agent 可把 Airtable 当 CRM、内容日历
- 场景：客户跟进看板、自媒体选题库、供应商管理
- 匹配度 ★★★☆☆

10. Together AI — AI模型｜开源模型推理
- 网址 https://www.together.ai
- 注册：官网 Sign up 注册获取 API Key
- 额度：定价页：Ternary Bonsai 27B 标注 Free；其余模型按 token 计费，试用额度以官方控制台为准
- 用法：OpenAI 兼容接口，改 base_url 即可用 OpenAI SDK
- Agent 适配：OpenAI 兼容，Agent 框架零改动接入，可切换多种开源模型
- 场景：低成本批量翻译、客服草稿、内容改写
- 匹配度 ★★★☆☆
