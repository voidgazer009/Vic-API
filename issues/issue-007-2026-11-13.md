# Vic API 精选 · 第 007 期 · 2026-11-13（周五）
主题：给 Agent 装上记忆、沙盒与浏览器——向量库、记忆层、云浏览器、物流与天气 API 精选
额度均于 2026-11-13 核对官方页面（未显示数字的写明以控制台为准）。

1. Pinecone — 向量数据库｜Agent 长期知识库
- 网址 https://www.pinecone.io
- 注册：app.pinecone.io 注册，Starter 免费计划
- 额度：定价页：Starter 免费，最多 5 个索引、2GB 存储、每月 200 万写入单元、100 万读取单元；内置嵌入模型每月 500 万 token；仅 us-east-1
- 用法：控制台建索引拿 API Key，用 Python / JS SDK upsert 与 query
- Agent 适配：有官方 SDK、内置嵌入与重排（Inference）和 Assistant，可直接做 RAG 知识库
- 场景：外贸产品资料库、客服问答、自媒体选题素材检索
- 匹配度 ★★★★☆

2. Qdrant Cloud — 向量数据库｜永久免费 1GB 集群
- 网址 https://qdrant.tech
- 注册：cloud.qdrant.io 注册，Free Tier 无需升级即可使用
- 额度：定价页：Free Tier 永久免费，单节点 0.5 vCPU / 1GB RAM / 4GB 磁盘，含部分模型的免费云端推理
- 用法：控制台建集群拿 URL 与 API Key，REST / gRPC 或官方 SDK；也可开源自部署
- Agent 适配：开源，支持混合检索，主流 Agent 框架均有集成
- 场景：客户资料语义检索、竞品文案库、物流 FAQ 机器人
- 匹配度 ★★★★☆

3. Mem0 — Agent 记忆层｜给 Agent 长期记忆
- 网址 https://mem0.ai
- 注册：官网 Get Started 注册，免费计划自带你的 LLM Key
- 额度：定价页：Free 不限终端用户；前 30 天每月 1 万次添加、1000 次检索；用自己的 LLM Key 为每月 5 万次添加、1 万次检索；超出按量计费且可设月度上限
- 用法：SDK 的 add / search 两个调用，官方提供 MCP 集成
- Agent 适配：开源，有 MCP，让 Agent 记住客户偏好与历史对话
- 场景：外贸客户跟进记忆、个人 AI 助理、自媒体风格偏好记忆
- 匹配度 ★★★★★

4. E2B — 代码沙盒｜Agent 的云端电脑
- 网址 https://e2b.dev
- 注册：console.e2b.dev 注册，免费 Hobby，无需信用卡
- 额度：定价页：Hobby 免费，含一次性 100 美元用量额度；单次会话最长 1 小时；10 个并发沙盒；Pro 为 150 美元/月
- 用法：pip install e2b 或 npm i e2b，几行代码启动沙盒并运行代码
- Agent 适配：专为 AI Agent 设计，安全执行模型生成的代码、数据分析与文件处理
- 场景：自动处理报价 Excel、批量转换物流单据、数据清洗
- 匹配度 ★★★★☆

5. Browserbase — 云浏览器｜让 Agent 会上网操作
- 网址 https://www.browserbase.com
- 注册：官网 Sign up，Free 计划
- 额度：定价页：Free 每月 0 美元，3 个并发浏览器、1 浏览器小时、1000 次 Search、1000 次 Fetch，单会话 15 分钟
- 用法：Playwright / Puppeteer / Selenium 连接云端浏览器，或用开源 Stagehand 自然语言操作
- Agent 适配：有 MCP 与 Stagehand SDK，处理无 API 的网站登录、表单与抓取
- 场景：查询船公司网站、填写海关或平台表单、竞品价格抓取
- 匹配度 ★★★★☆

6. LangSmith — Agent 观测｜追踪调试 Agent
- 网址 https://www.langchain.com/langsmith
- 注册：官网注册，Developer 计划
- 额度：定价页：Developer 每席位每月 0 美元，含 5000 个基础 trace/月，之后按量付费；1 个席位，社区支持
- 用法：设置环境变量后自动记录调用链，支持评估与提示词管理
- Agent 适配：兼容 LangChain 与其他框架，查看每步工具调用、成本与延迟
- 场景：排查外贸 Agent 为什么回复错、优化成本、对比提示词
- 匹配度 ★★★☆☆

7. Cloudinary — 图片视频处理｜自媒体素材自动化
- 网址 https://cloudinary.com
- 注册：cloudinary.com/users/register_free 注册，无需信用卡
- 额度：定价页：Free 永久免费，每月 25 credits（1 credit = 1000 次转换 或 1GB 存储 或 1GB 图片带宽）；3 用户；含 MCP 服务器访问
- 用法：上传 API 后用 URL 参数实时裁剪、压缩、转格式
- Agent 适配：官方提供 MCP Server，Agent 可直接上传与变换素材
- 场景：自动生成多平台封面尺寸、产品图批量压缩、视频转码
- 匹配度 ★★★★☆

8. Shippo — 物流运费｜多承运商比价与面单
- 网址 https://www.shippo.com
- 注册：API 门户注册，API Starter 无月费
- 额度：API 定价页：每月前 30 张面单免费，之后 7 美分/张；追踪 2 美分/次、比价 1 美分/次生成（需另付）；官方文档称有托管 MCP Server
- 用法：REST API 或 SDK 创建 shipment、取运费、买面单、追踪
- Agent 适配：有 MCP Server，Agent 可比较 40+ 承运商运费
- 场景：跨境小包比价、自动生成面单、给客户推送追踪
- 匹配度 ★★★☆☆

9. WeatherAPI.com — 天气数据｜免费 10 万次调用
- 网址 https://www.weatherapi.com
- 注册：官网 Get free API key
- 额度：定价页：Free 永久免费，每月 10 万次调用，含 3 天预报与前 1 天历史、实时、搜索、IP 定位；官方称免费版可用于商业应用；含 MCP 服务器
- 用法：GET 请求带 key 与城市参数，返回 JSON
- Agent 适配：官方 MCP Server，Agent 直接查天气与空气质量
- 场景：港口天气延误预警、物流排期、户外内容选题
- 匹配度 ★★★☆☆

10. OpenWeather — 天气数据｜每月 100 万次免费
- 网址 https://openweathermap.org/api
- 注册：官网注册并订阅 Free 计划获取 Key
- 额度：定价页：Free 每分钟 60 次、每月 100 万次，含当前天气与 5 天 3 小时预报；One Call 每天前 1000 次免费，超出 0.0015 美元/次
- 用法：GET 请求带 appid 与经纬度或城市名
- Agent 适配：站点提供 llms.txt 与 Agent 入口，REST JSON 易于调用
- 场景：运输路线天气风险、出行与活动内容、跨国交付排期
- 匹配度 ★★★☆☆
