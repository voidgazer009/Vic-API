# Vic API 精选 · 第 004 期 · 2026-11-10（周二）
主题：让 Agent 听得见、找得到、能约人——语音、地图、新闻、邮件与排期的 10 个免费 API
额度均于 2026-11-10 核对官方页面。

1. Deepgram — 语音识别｜音频秒变文字
- 网址 https://deepgram.com ；定价 https://deepgram.com/pricing ；文档 https://developers.deepgram.com
- 注册：deepgram.com 邮箱/Google/GitHub 注册，无需信用卡 → Console 创建 API Key
- 额度：定价页显示 Free 为 $200 额度，之后按量付费；无最低消费、无过期、无需信用卡
- 用法：POST https://api.deepgram.com/v1/listen 上传音频或 URL，选 nova-3 模型；另有 TTS 与 Voice Agent API
- Agent 适配：官方 MCP 服务器、CLI（28 个 API 命令）与 Agent Skills
- 场景：客户电话/会议录音转写、视频口播出字幕、给 Agent 做语音客服
- 匹配度 ★★★★☆

2. Geoapify — 地理位置｜地址、路线、地点一站式
- 网址 https://www.geoapify.com ；定价 https://www.geoapify.com/pricing
- 注册：myprojects.geoapify.com 注册，Free 无需信用卡 → 创建项目获取 API Key
- 额度：Free 每天 3,000 credits，最高 5 请求/秒；官方 FAQ 注明可用于商业项目，需在额度内
- 用法：GET https://api.geoapify.com/v1/geocode/search?text=地址&apiKey=KEY ；另有路线、等时圈、地点搜索
- Agent 适配：纯 REST + JSON，易封装为 Agent 工具
- 场景：清洗客户地址、估算仓库到客户的路线、查找港口/仓库周边服务商
- 匹配度 ★★★★☆

3. Serper — 搜索｜Google 结果 API
- 网址 https://serper.dev
- 注册：serper.dev 注册，无需信用卡 → Dashboard 获取 API Key
- 额度：首页写明注册送 2,500 次免费查询；付费 Starter $50 / 5 万 credits
- 用法：POST https://google.serper.dev/search ，Header X-API-KEY，Body {"q":"关键词"}；支持图片、新闻、地图、购物、学术
- Agent 适配：LangChain 等框架常见内置工具，返回结构化 JSON
- 场景：Agent 查竞品价格、海外买家、Google 购物与新闻
- 匹配度 ★★★★☆

4. Pixabay API — 自媒体素材｜免版权图片视频
- 网址 https://pixabay.com/api/docs/
- 注册：pixabay.com 注册账号后在 API 文档页获取 Key
- 额度：默认每个 Key 每 60 秒 100 次请求；要求缓存结果 24 小时并标注来源
- 用法：GET https://pixabay.com/api/?key=KEY&q=关键词 ，返回图片/视频 JSON（另有 /api/videos/）
- Agent 适配：简单 REST，可作为配图工具
- 场景：为文章、短视频、产品页自动找免版权配图
- 匹配度 ★★★☆☆

5. Cal.com — 自动排期｜Agent 约客户
- 网址 https://cal.com ；定价 https://cal.com/pricing ；API https://cal.com/docs/api-reference/v2/introduction
- 注册：cal.com 注册，个人 Free 计划永久免费 → 设置中创建 API Key
- 额度：Free 为 1 用户、无限链接与日历、邮件和短信通知；定价页写明免费无使用限制
- 用法：API v2 提供 Bookings、Slots、Schedules 等接口，可查空档并创建预约
- Agent 适配：官方 MCP 服务器与 Agent 快速入门文档
- 场景：Agent 回复客户询盘时直接发预约链接、自动约视频会议
- 匹配度 ★★★★☆

6. GNews — 新闻｜8 万+ 来源的新闻搜索
- 网址 https://gnews.io ；定价 https://gnews.io/pricing
- 注册：gnews.io 注册，无需信用卡 → Dashboard 获取 apikey
- 额度：Free 每天 100 请求、每次最多 10 篇、12 小时延迟、近 30 天历史、正文截断 250 字符；仅限非商业使用
- 用法：GET https://gnews.io/api/v4/search?q=AI&lang=en&apikey=KEY
- Agent 适配：JSON 响应简洁，适合做新闻监控工具（商用需付费计划）
- 场景：监控行业新闻、关税政策、选题灵感
- 匹配度 ★★★☆☆

7. Brevo — 邮件营销｜事务与营销邮件
- 网址 https://www.brevo.com ；定价 https://www.brevo.com/pricing/
- 注册：brevo.com 注册，账号需审核通过后才能发送 → SMTP & API 页创建 Key
- 额度：官方定价页 FAQ 写明账号通过审核后可每天发送最多 300 封邮件
- 用法：POST https://api.brevo.com/v3/smtp/email ，Header api-key
- Agent 适配：定价页导航列有 Email MCP 产品
- 场景：外贸开发信序列、订单确认邮件、Newsletter
- 匹配度 ★★★★☆

8. IPinfo Lite — IP 定位｜免费无限 IP 查询
- 网址 https://ipinfo.io/lite ；定价 https://ipinfo.io/pricing
- 注册：ipinfo.io 邮箱注册，无需信用卡 → 获取 Token
- 额度：官方页面写明国家级定位与 ASN，无月费、无需信用卡、API 请求无限制
- 用法：GET https://ipinfo.io/lite/8.8.8.8?token=TOKEN
- Agent 适配：轻量 REST，适合作为 Agent 的辅助判断工具
- 场景：识别网站访客来自哪个国家做外贸线索评分、风控订单
- 匹配度 ★★★☆☆

9. Alpha Vantage — 金融数据｜股票外汇加密
- 网址 https://www.alphavantage.co ；支持页 https://www.alphavantage.co/support/
- 注册：alphavantage.co/support 页面免费领取 API Key
- 额度：官方支持页写明免费每天 25 次请求；已验证开源/教育项目可无限
- 用法：GET https://www.alphavantage.co/query?function=FX_DAILY&from_symbol=USD&to_symbol=CNY&apikey=KEY
- Agent 适配：站点提供 MCP 相关支持，细节以官方文档为准
- 场景：汇率与大宗商品趋势监控、跨境定价参考
- 匹配度 ★★★☆☆

10. ntfy — 推送通知｜一行 curl 推手机
- 网址 https://ntfy.sh ；文档 https://docs.ntfy.sh/publish/
- 注册：无需注册，自选 topic 名在 App 订阅即可
- 额度：官方文档默认配置为每访客 60 次请求突发、每 5 秒补充 1 次；ntfy.sh 公共服务实际限额以官网为准
- 用法：curl -d "订单已发货" ntfy.sh/你的topic
- Agent 适配：HTTP 即可调用，零配置
- 场景：Agent 任务完成、异常、新询盘即时推送到手机
- 匹配度 ★★★★☆
