# Vic API 精选 · 第 005 期 · 2026-11-11（周三）
主题：给 Agent 装上「实时汇率、搜索抓取、记忆与数据库、社媒发布」——10 个有免费层的 API
额度均于 2026-11-11 核对官方页面。

1. ExchangeRate-API — 外贸汇率｜165 种货币报价
- 网址 https://www.exchangerate-api.com ；文档 https://www.exchangerate-api.com/docs/overview
- 注册：官网 Get Free Key，邮箱注册并确认邮件，Free 无需信用卡
- 额度：定价页显示 Free 每月 1.5K 次请求，每天更新一次，含历史数据
- 用法：HTTPS GET 请求即可，返回 JSON，无需 SDK
- Agent 适配：纯 REST + JSON，Agent 以一次 HTTP 工具调用即可换算报价
- 场景：外贸报价单自动换算多币种、跨境店铺本地化价格
- 匹配度 ★★★★☆

2. Open Exchange Rates — 外贸汇率｜小时级更新汇率
- 网址 https://openexchangerates.org
- 注册：官网 signup 注册免费计划获取 App ID
- 额度：页面显示 Free 计划每小时更新（基础货币为 USD），每月最多 1,000 次请求
- 用法：GET /api/latest.json?app_id=你的ID，返回 200+ 货币汇率
- Agent 适配：REST + JSON，可与 ExchangeRate-API 互为备份
- 场景：外贸成本核算、汇率波动提醒、对账
- 匹配度 ★★★☆☆

3. SerpApi — 搜索抓取｜结构化谷歌搜索结果
- 网址 https://serpapi.com ；定价 https://serpapi.com/pricing
- 注册：serpapi.com 邮箱注册并验证手机号，在 Dashboard 复制 API Key
- 额度：定价页显示 Free 每月 250 次搜索，吞吐每小时 50 次
- 用法：GET https://serpapi.com/search?engine=google&q=关键词&api_key=KEY
- Agent 适配：官方提供多语言 SDK，并可被 Agent 作为搜索工具调用
- 场景：外贸找买家与竞品、自媒体选题热度、价格监控
- 匹配度 ★★★★☆

4. ScrapingBee — 网页抓取｜自动处理代理与渲染
- 网址 https://www.scrapingbee.com ；定价 https://www.scrapingbee.com/pricing/
- 注册：官网邮箱注册，无需信用卡
- 额度：定价页显示注册即送 1,000 个免费 API credits（一次性试用额度）
- 用法：GET 请求带 api_key 与目标 url，可选 JavaScript 渲染、代理
- Agent 适配：REST 即用，适合作为 Agent 的「读网页」工具
- 场景：抓取供应商页面、竞品商品信息、行业资讯
- 匹配度 ★★★★☆

5. Linkup — AI 搜索｜Agent 专用搜索
- 网址 https://www.linkup.so ；定价 https://www.linkup.so/pricing
- 注册：官网 Get started 注册获取 API Key
- 额度：定价页写明可免费运行 4,000 次查询，之后按量付费；具体计费以官方控制台为准
- 用法：REST 调用 search / fetch 接口，返回带来源的答案或原文
- Agent 适配：定位为 AI Agent 的生产级网页搜索，带 API 文档与 SDK
- 场景：Agent 实时查证、行业调研、带引用的内容写作
- 匹配度 ★★★★☆

6. GitHub REST API — 开发者生态｜代码仓库全自动
- 网址 https://docs.github.com/en/rest
- 注册：github.com 注册账号 → Settings 创建 Personal Access Token
- 额度：官方文档：未认证请求每小时 60 次；认证用户每小时 5,000 次
- 用法：GET https://api.github.com/repos/{owner}/{repo}，Header 带 Bearer Token
- Agent 适配：官方 SDK 与 CLI，Agent 可自动管理仓库、读 Issue、发 Release
- 场景：一人公司的代码与文档自动化、监控开源项目更新、发现新 API
- 匹配度 ★★★★☆

7. Upstash — Agent 记忆｜Serverless Redis 与队列
- 网址 https://upstash.com ；定价 https://upstash.com/pricing
- 注册：console.upstash.com 邮箱/GitHub/Google 登录，创建数据库
- 额度：定价页显示 Free 为 250 MB 数据、每月 10 GB 带宽、每月 50 万次命令
- 用法：REST 或 Redis 协议读写；另有 QStash 消息队列、Vector 向量库
- Agent 适配：HTTP REST 接口，适合 Agent 存会话记忆、缓存与定时任务
- 场景：Agent 记忆、限流缓存、定时回调、去重
- 匹配度 ★★★★☆

8. Neon — 一人公司后端｜Serverless Postgres 数据库
- 网址 https://neon.com ；定价 https://neon.com/pricing
- 注册：neon.com 邮箱/GitHub 注册，Free 无需信用卡
- 额度：定价页显示 Free 永久：100 个项目、每项目每月 100 CU 小时、每项目 1 GB 存储
- 用法：创建项目获取连接串，用任意 Postgres 客户端或 HTTP 驱动连接
- Agent 适配：标准 Postgres，Agent 可直接写 SQL，可配合 MCP 管理数据库
- 场景：客户线索库、订单与物流记录库、Agent 长期数据存储
- 匹配度 ★★★★☆

9. Scrapingdog — 网页抓取｜低门槛抓取与搜索接口
- 网址 https://www.scrapingdog.com ；定价 https://www.scrapingdog.com/pricing
- 注册：官网邮箱注册，无需信用卡
- 额度：定价页显示 Free 永久 100 次请求 credits，1 并发，可访问所有 API
- 用法：GET 请求带 api_key 与 url，另提供谷歌搜索等专用接口
- Agent 适配：REST 调用，失败请求不扣费，适合 Agent 做兜底抓取
- 场景：电商价格与评论抓取、外贸获客名单、社媒数据采集
- 匹配度 ★★★☆☆

10. Ayrshare — 社媒发布｜一键发 14 个平台
- 网址 https://www.ayrshare.com ；定价 https://www.ayrshare.com/pricing/
- 注册：官网注册，开始 28 天免费试用，试用为 Launch 计划权限
- 额度：定价页显示 28 天免费试用；试用后保留 Launch 或切换付费计划，具体额度以官方控制台为准
- 用法：POST /api/post 带文案、图片与平台列表，一次发布多个平台
- Agent 适配：REST API，Agent 可生成文案后直接排期发布
- 场景：自媒体多平台同步发布、定时发帖、评论管理
- 匹配度 ★★★☆☆
