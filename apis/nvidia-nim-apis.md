# NVIDIA NIM APIs

> AI模型｜免费推理

- 方向：一人公司｜分类：AI模型
- 收录：第 010 期（2026-11-16），额度核对日期见当期
- 网址：https://build.nvidia.com

**网址**：https://build.nvidia.com ；文档 https://docs.api.nvidia.com/nim/docs/api-quickstart

**注册**：用邮箱注册 NVIDIA 开发者账号后生成 API Key

**额度**：官方页面写明提供免费推理端点，具体速率以官方控制台为准

**用法**：OpenAI 兼容接口，base_url 指向 https://integrate.api.nvidia.com/v1，Key 填 YOUR_API_KEY

**Agent 适配**：OpenAI 兼容，现有 Agent 框架改 base_url 即可接入；页面列有 DeepSeek、Nemotron 等模型

**场景**：给低成本客服和文案 Agent 增加一个免费备用模型

**匹配度**：★★★★☆
