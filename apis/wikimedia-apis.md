# Wikimedia APIs

> 自媒体素材｜维基素材

- 方向：自媒体｜分类：自媒体素材
- 收录：第 010 期（2026-11-16），额度核对日期见当期
- 网址：https://api.wikimedia.org

**网址**：https://api.wikimedia.org ；限速说明 https://www.mediawiki.org/wiki/Wikimedia_APIs/Rate_limits

**注册**：只读可免注册；必须带含联系方式的 User-Agent

**额度**：官方 2026 年起按用户限速；建议并发 3 个或更少；具体上限以官方页面为准，规则仍在调整

**用法**：REST 或 Action API，读取词条摘要、当日精选内容、图片版权信息

**Agent 适配**：JSON 接口丰富，可查事实、找 Commons 图片，并读取署名信息

**场景**：写科普短视频脚本前让 Agent 查证事实并找可商用图片

**匹配度**：★★★★☆
