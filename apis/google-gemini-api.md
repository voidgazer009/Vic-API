# Google Gemini API

> 大脑｜AI 模型

- 方向：一人公司｜分类：AI模型
- 收录：第 001 期（2026-11-06），额度核对日期见当期
- 网址：https://aistudio.google.com

**网址**：https://aistudio.google.com ；文档 https://ai.google.dev/gemini-api/docs

**注册**：Google 账号登录 AI Studio → Get API key → 自动建项目，免费层无需绑卡

**额度**：Free 层（活跃项目即可），按 RPM/TPM/RPD 计，按项目计算不按 Key；每日额度太平洋时间午夜重置；具体每模型限额在 AI Studio 的 Rate limit 页查看

**用法**：POST generativelanguage.googleapis.com，或 google-genai SDK；支持 OpenAI 兼容端点

**Agent 适配**：函数调用、结构化输出、长上下文、多模态（图/音/视频）

**场景**：外贸开发信撰写与多语种翻译、产品图识别、自媒体脚本

**匹配度**：★★★★★
