# Tomorrow.io Weather API

> 物流天气｜全球天气与MCP

- 方向：物流｜分类：物流天气
- 收录：第 015 期（2026-11-21），额度核对日期见当期
- 网址：https://www.tomorrow.io/weather-api/

**网址**：https://www.tomorrow.io/weather-api/ ；文档 https://docs.tomorrow.io/reference/welcome

**注册**：官网注册后在开发者后台获取 API Key

**额度**：官方限流文档写明按套餐限制每秒、每小时和每天的请求数，具体免费数字以官方控制台为准

**用法**：GET https://api.tomorrow.io/v4/weather/forecast?location=22.3,114.2&apikey=YOUR_API_KEY

**Agent 适配**：REST + JSON，文档目录列出官方 Tomorrow.io MCP，Agent 可直接接入

**场景**：Agent 在发货前查询货运沿线的风雨和极端天气，提前预警延误

**匹配度**：★★★☆☆
