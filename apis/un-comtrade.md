**网址**：https://comtradeplus.un.org ；说明 https://uncomtrade.org/docs/subscriptions

**注册**：免费注册 UN Comtrade 账号 → My Comtrade → My API portal 申请免费订阅 Key

**额度**：免费 Basic 账号 500 次/天，每次最多 10 万条记录，限速 5 次/秒；不注册的 preview 接口每次 500 条、1 次/秒

**用法**：GET https://comtradeapi.un.org/data/v1/get/C/A/HS ，按 HS 编码、国家、年份查询；有 Python/R 库

**Agent 适配**：结构化 JSON，适合让 Agent 自动出「某产品主要进口国」报告

**场景**：选品与目标市场分析、按 HS 编码看各国进口额和趋势
