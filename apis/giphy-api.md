# GIPHY API

> 自媒体素材｜全球最大 GIF 库

- 方向：自媒体｜分类：自媒体素材
- 收录：第 011 期（2026-11-17），额度核对日期见当期
- 网址：https://developers.giphy.com/docs/api/

**网址**：https://developers.giphy.com/docs/api/ ；控制台 https://developers.giphy.com/dashboard/

**注册**：先在开发者控制台创建账号，再点 Create an API Key

**额度**：新建 Key 为 Beta，每小时限 100 次搜索或调用；需要更多须申请生产 Key

**用法**：GET https://api.giphy.com/v1/gifs/search?api_key=YOUR_API_KEY&q=cat&limit=5

**Agent 适配**：REST + JSON；官方要求在客户端调用、不得缓存素材并需显示 Powered By GIPHY

**场景**：Agent 为社媒帖子匹配表情动图和话题梗图

**匹配度**：★★★☆☆
