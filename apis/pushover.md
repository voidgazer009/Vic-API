**网址**：https://www.pushover.net

**注册**：官网注册账号，在 iOS/Android 安装 App（30 天免费试用，之后为一次性购买）

**额度**：官网：每位用户每月可免费发送最多 10,000 条消息

**用法**：POST https://api.pushover.net/1/messages.json，带 token、user、message

**Agent 适配**：一条 HTTP 请求即可让 Agent 把结果、告警推到手机

**场景**：Agent 任务完成提醒、订单/货件异常告警、每日汇总推送

**匹配度**：★★★★☆
