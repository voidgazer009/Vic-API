# Shotstack

> 自媒体视频｜API 合成短视频

- 方向：自媒体｜分类：自媒体视频
- 收录：第 012 期（2026-11-18），额度核对日期见当期
- 网址：https://shotstack.io/pricing/

**网址**：https://shotstack.io/pricing/ ；文档 https://shotstack.io/docs/

**注册**：注册即可用沙盒，无需信用卡

**额度**：注册送 10 个额度（30 天有效）；免费沙盒；按需付费每分钟视频 0.20 美元

**用法**：POST https://api.shotstack.io/edit/stage/render ，请求头 x-api-key: YOUR_API_KEY ，正文为 JSON 时间线

**Agent 适配**：官方支持 MCP 与命令行，也有 Make、Zapier、n8n 集成

**场景**：Agent 把文案、图片和配音自动拼成竖屏短视频

**匹配度**：★★★★☆
