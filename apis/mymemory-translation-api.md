# MyMemory Translation API

> 外贸翻译｜翻译库

- 方向：外贸｜分类：外贸翻译
- 收录：第 010 期（2026-11-16），额度核对日期见当期
- 网址：https://mymemory.translated.net

**网址**：https://mymemory.translated.net ；文档 https://mymemory.translated.net/doc/spec.php

**注册**：匿名可用；在参数 de 里填有效邮箱即可提升额度

**额度**：匿名每天 5000 字符；填邮箱每天 5 万字符；每次请求 q 最多 500 字节

**用法**：GET https://api.mymemory.translated.net/get?q=Hello World!&langpair=en|it

**Agent 适配**：简单 GET，适合短句、标题、产品名批量翻译；长文建议拆段

**场景**：外贸询盘标题、产品卖点短句快速多语言翻译

**匹配度**：★★★☆☆
