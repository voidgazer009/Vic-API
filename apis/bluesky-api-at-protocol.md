# Bluesky API (AT Protocol)

> 自媒体发布｜开放社交

- 方向：一人公司｜分类：开放社交
- 收录：第 010 期（2026-11-16），额度核对日期见当期
- 网址：https://bsky.social

**网址**：https://bsky.social ；文档 https://docs.bsky.app

**注册**：注册 Bluesky 账号即可；读取公开资料无需登录

**额度**：以官方控制台为准（限速文档页为动态页面，未取到具体数字）

**用法**：GET https://api.bsky.app/xrpc/app.bsky.actor.getProfile?actor=bsky.app 读取公开资料；发帖需登录会话

**Agent 适配**：开放协议，读取与发帖都是 HTTP 接口，适合自动化发布

**场景**：把每日精选自动发到海外账号，并抓取评论做二次运营

**匹配度**：★★★★☆
