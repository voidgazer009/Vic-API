# Pixabay API

> 自媒体素材｜免版权图片视频

- 方向：自媒体｜分类：自媒体素材
- 收录：第 004 期（2026-11-10），额度核对日期见当期
- 网址：https://pixabay.com/api/docs/

**网址**：https://pixabay.com/api/docs/

**注册**：pixabay.com 注册账号后在 API 文档页获取 Key

**额度**：默认每个 Key 每 60 秒 100 次请求；要求缓存结果 24 小时并标注来源

**用法**：GET https://pixabay.com/api/?key=KEY&q=关键词 ，返回图片/视频 JSON（另有 /api/videos/）

**Agent 适配**：简单 REST，可作为配图工具

**场景**：为文章、短视频、产品页自动找免版权配图

**匹配度**：★★★☆☆
