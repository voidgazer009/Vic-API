**注册**：无需注册，无需 Key

**额度**：官方 README 写明无请求限制，支持 200+ 币种，每日更新

**用法**：GET https://cdn.jsdelivr.net/npm/@fawazahmed0/currency-api@latest/v1/currencies/usd.json 返回以美元为基准的汇率；备用地址 https://latest.currency-api.pages.dev/v1/currencies/usd.json

**Agent 适配**：静态 JSON，可按日期取历史汇率，代码里建议加备用地址回退

**场景**：多币种报价单、利润核算时让 Agent 批量换算
